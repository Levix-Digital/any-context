# Release Notes — Kestrel Dashboard 3.3

> Fictitious document of Kestrel Analytics. Released on 2026-06-02.

## New

- Export any chart to Parquet.
- Shared dashboards can now be protected with a password.

## Fixed

- CSV export now always uses UTF-8, which fixes broken accented characters in spreadsheets.
- Scheduled weekly reports were sent twice on Mondays.

## Changed

- The minimum supported browser is now the latest two versions of each major browser.
