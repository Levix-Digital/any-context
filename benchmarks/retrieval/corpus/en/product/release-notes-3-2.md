# Release Notes — Kestrel Dashboard 3.2

> Fictitious document of Kestrel Analytics. Released on 2026-03-10.

## New

- Export any chart to CSV.
- Dark mode for all dashboards.
- Scheduled reports by e-mail, daily or weekly.

## Removed

- The legacy XML import was removed in 3.2. Use the JSON or CSV import instead.

## Known issues

- CSV export uses the system encoding, so accented characters may break in some spreadsheets.
