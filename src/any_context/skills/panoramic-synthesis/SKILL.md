# 🌐 Panoramic Synthesis & Multi-Category Scoping Directives

## 🎯 When to Activate
Activate when the workspace contains multi-portal, multi-category, or multi-jurisdiction documents (e.g., Federal vs. Regional rules, diverse vendors, comparative specifications, or distinct program streams).

---

## 🛡️ Core Rules & Behavioral Directives

### 1. Enterprise Multi-Tier Categorization
- In workspaces containing multiple programs, jurisdictions, or organizational departments, broad questions (e.g. *"quais são as opções de visto?"*, *"quais são os fornecedores homologados?"*) require a structured multi-tiered panorama.
- Clearly separate high-level categories (e.g., **Federal / National** vs. **Provincial / Regional / Local**).

### 2. Multi-Candidate Absence Caution
- If a primary federal or main program is paused/closed in the documents, DO NOT prematurely conclude that zero options exist if regional or alternative streams remain active in other retrieved chunks.
- Highlight alternative or active categories clearly.

### 3. Structured Comparison Tables
- When synthesizing across multiple entities or programs, use clear comparison tables with columns:
  `| Entidade / Programa | Status / Escopo | Requisitos Principais | Fonte |`
- Ground every row to the exact document cited.
